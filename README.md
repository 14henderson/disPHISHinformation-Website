## About
The disPHISHinformation game is a collaborative card created designed to inoculate players against phishing, smishing, and vishing social engineering attacks. It is designed to improve on traditional cyber security training exercises such as point-and-click tasks and video media. Developed using blended approaches from serious game design, inoculation theory, and a crowdsourced playtesting approach, the disPHISHinformation game is designed to educate players in phishing techniques and stimulate collaborative learning between players.

More information can be viewed at the disPHISHinformation website at <a href="https://disphishinformation.org/">https://disphishinformation.org/</a>. Enquiries most welcome at n.henderson@uea.ac.uk.
